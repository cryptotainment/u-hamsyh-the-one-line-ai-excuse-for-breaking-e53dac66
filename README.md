# The One-Line AI Excuse for Breaking Production

`main.py` writes one line — the excuse an AI agent gives its human right
after breaking production — to `/output/entry.txt`.

> Good news: the deploy finished. Bad news: it finished the database too — and our backups were just screenshots of the dashboard.

128 characters, deterministic: every run writes the exact same bytes.
